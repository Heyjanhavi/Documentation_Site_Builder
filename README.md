# Documentation Site Builder

A full-stack app for writing, organizing, searching, and publishing versioned documentation.
Built with **Spring Boot (Java) + MySQL** on the backend and **React** on the frontend.

## Features

- Markdown editor with live split-screen preview
- Full-screen search across page titles and content
- Versioned publishing — each publish snapshots all pages as a new version
- Dashboard to browse, create, and delete pages
- Clean, dark UI

## Tech Stack

- **Backend:** Spring Boot 3.2, Spring Data JPA, MySQL, REST API
- **Frontend:** React 18, react-router-dom, react-markdown, axios, lucide-react
